# CloudTune NX v0.1.0 · 开发预览

CloudTune NX 将网易云音乐带到 Nintendo Switch 原生自制界面。
这是首个开发预览版本，面向愿意反馈问题的测试用户。
**真实 Switch 上的 Atmosphère 游戏内 BGM、覆盖层与休眠恢复仍待实机验收。**

## 本版内容

- 基于 Borealis / NanoVG 的中文界面，支持手柄、摇杆和触摸；标准弹窗共用
  bundled Noto CJK 字体，保留手柄提示和系统图标。
- 热门歌单、排行榜、新碟、搜索、歌单/专辑/歌手详情，以及分页资料库。
- 二维码和手机号验证码登录流程、会话保存、喜欢的音乐、创建/收藏歌单、
  收藏专辑、订阅电台与音乐云盘。
- 每日推荐、私人 FM、心动模式，以及歌曲喜欢和歌单/专辑收藏操作入口。
- **33⅓ RPM 旋转黑胶唱片**、封面、唱臂、逐行双语歌词和迷你播放器；
  暂停会冻结唱片，恢复后继续旋转。
- MP3 渐进 HTTPS 播放、切歌、暂停、跳转、音量、循环和随机，
  SD 缓存按音质/会话区分，并刷新失效播放地址。
- 独立 Atmosphère 后台服务和 Tesla / Ultrahand 兼容覆盖层。
  服务不可用时使用前台播放器；再次打开 NRO 可恢复队列而不自动开始播放。
- 完整移植参考客户端的 **49 个服务/下载方法和 4 个会话辅助方法**，
  实现 WEAPI、EAPI、XEAPI，无需另外部署 API 中转服务器。

## 下载与安装

| 附件 | 用途 |
| --- | --- |
| `CloudTuneNX-0.1.0-sd.zip` | 唯一需要解压到 SD 卡的安装包 |
| `CloudTuneNX-0.1.0-symbols.zip` | 匹配本版二进制的 ELF，保留在电脑上排查崩溃 |
| `CloudTuneNX-0.1.0-docs.zip` | 离线文档与许可证 |
| `CloudTuneNX-0.1.0-manifest.json` | 源提交与包内文件哈希 |
| `SHA256SUMS` | 发布附件的 SHA-256 校验值 |

下载 SD 包和 `SHA256SUMS` 到同一目录，执行
`sha256sum --check --ignore-missing SHA256SUMS` 并确认 SD 包为 `OK`。
只将 SD 包解压到 SD 卡根目录，随后重启 Atmosphère。
通过 Homebrew Menu 打开 `switch/CloudTune/CloudTune.nro`；
覆盖层位于 `switch/.overlays/CloudTune.ovl`，需要另行安装兼容加载器。
建议使用 R + 游戏的完整应用模式启动 Homebrew Menu。

后台程序位于 `atmosphere/contents/42000000004E434D/exefs.nsp`；
这是系统模块文件，不是用于游戏安装器的 NSP。只有播放栏明确显示后台服务
正在工作时，才进入退出 NRO 和游戏并行播放的实机测试。

已有预览版用户请保留 `config/netease-switch/`，其中的会话、设置和队列
无需因品牌更名而迁移。详细步骤见
[安装指南](https://github.com/tiansongyu/cloudtune-nx/blob/v0.1.0/docs/INSTALLING.md)。

## 已知边界与反馈

- 当前播放器解码 MP3，提供标准/较高/极高三档；不宣称已支持 FLAC/AAC 播放。
- 单次后台队列最多 512 首；较大远程歌单可浏览，按当前曲目所在窗口传递。
- 会员、版权、地区和试听限制由网易云决定；不会绕过账号权益。
- 收藏写入、短信流程及异常登录状态需要进一步验证。
- 游戏内混音、后台长期运行、休眠/唤醒、蓝牙和底座切换请按
  [实机验收表](https://github.com/tiansongyu/cloudtune-nx/blob/v0.1.0/docs/HARDWARE_TESTING.md)
  记录。Eden 的 SSL 验证限制见模拟器文档。

请在 [Issues](https://github.com/tiansongyu/cloudtune-nx/issues) 提供版本、
文件 SHA-256、HOS/Atmosphère/覆盖层加载器版本、复现步骤和脱敏日志。
不要附 cookie、二维码 key、手机号、账号响应或私人音乐缓存。
