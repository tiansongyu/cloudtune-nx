# CloudTune NX v0.3.1 · AirPlay 连接恢复

- 修复未播放的探测连接阻塞同一手机真正播放连接、返回 `453` 的问题。
- 单次会话内存分配失败后保留发现与监听，手机可以重新连接；正在播放的会话仍禁止抢占。
- 增加有大小上限的接收和音频输出阶段日志，用于定位连接后无声，不记录账号、密钥或音频内容。
- 保留 v0.3.0 的后台播放优化、2 MiB 内存限制、系统资源检查和原有 IPC 接口。

主机与 UBSan 各通过 33 项测试，ASan 协议回归通过。独立 pyatv 客户端完成
探测连接交接后的实际 PCM 输出；Switch 原生模拟器通过身份校验、AAC 接管、
加密 ALAC、重复大封面、FLUSH 与 TEARDOWN，3,758 包零丢失。

目前为已安装本机的修复候选，**手机到实机 Switch 的复测尚未完成**。已复现的
连接问题不等于已确认手机故障的唯一原因。详情见[验证记录](https://github.com/tiansongyu/cloudtune-nx/blob/main/docs/VALIDATION.md)。

更新时请同步覆盖 NRO、后台 `exefs.nsp` 和覆盖层，然后完整重启。
已有 CloudTune 与 Tesla／Ultrahand 的自启标志应保留；私人照片仅留在本机版本。
