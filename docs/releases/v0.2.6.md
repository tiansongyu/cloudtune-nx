# CloudTune NX v0.2.6 · 列表切换与误播修复

## 修改

- 切换排行榜、搜索、发现音乐子栏目或音乐库分区时，立即清除旧列表并显示目标页面的加载状态。请求失败后保留目标页的错误提示，不再把上一页歌曲显示成新页面内容，也不会在尚未选择歌曲时误播旧列表。
- 触摸、方向键、A 键和首次播放使用屏幕当前显示的歌曲身份。后台更新列表顺序后仍播放所选歌曲；歌曲被移除、页面或账号已切换时拒绝过期操作，不会把旧行号应用到另一首歌。
- 播放队列内选曲同样按歌曲 ID 校验。身份核对、列表复制与队列更新在同一个锁内完成，消除两次快照之间的错位窗口。
- 加载更多失败时保留已加载内容，方便重试；切页与失败均不清空正在使用的播放队列。

保留 Borealis/C++ 架构、20 秒黑胶动画、照片版布局与此前的焦点和封面修复。本次修改界面和前台列表模型，不修改网络传输、音频解码、后台服务或 IPC 协议。公开版不包含私人照片。

## 验证

- 新增真实 Model / MusicView 回归测试，修复前复现错误，修复后通过；涵盖网络失败、列表重排、删除、账号变化、同路由内容更新、队列选曲及分页失败。
- 本地完整桌面测试 26/26 通过，Switch 三组件构建通过。
- 隔离虚拟桌面检查 1280×720、1920×1080；Eden 的实际 NRO 验证 FM → 断网 → 排行榜失败 → 播放无误触发 → 恢复网络重试，以及触摸选曲、手柄选曲、暂停、弹窗与返回焦点。
- 发布流程执行完整宿主测试、UndefinedBehaviorSanitizer、Switch 构建及五个附件上传后的回读校验。

使用 SD 安装包更新并保留 `config/netease-switch/`。账号曲目权益和实体 Switch 的游戏共存能力仍需对应账号及实机验收。
