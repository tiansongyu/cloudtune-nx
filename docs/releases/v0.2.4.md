# CloudTune NX v0.2.4 · 黑胶旋转速度调整

## 修改

- 黑胶由 1.8 秒一圈调整为 **20 秒一圈**（3 RPM、18°/秒），与网易云官方歌曲分享页的经典黑胶动画周期一致。
- 保持顺时针匀速旋转；暂停时停在当前角度，恢复播放后继续，减少动态时仍然停转。
- 同步原生界面、Web 设计原型、设计 token 和文档，保留 v0.2.3 的每日推荐 / 私人 FM 布局修复。

本次只修改视觉动画参数，不改变音乐倍速、音频、网络、账号或后台服务逻辑。公开版不含私人照片。

## 依据与验证

从[网易云官方歌曲页](https://music.163.com/m/song?id=186016)引用的
[官方样式](https://s3.music.126.net/mobile-new/Song$id$Index.64ac09c7ebc132715e3e.css)
核实 `circling 20s linear infinite`。该依据适用于所查的官方网页经典黑胶样式，不宣称所有客户端版本或付费皮肤都采用同一数值。

原生生产视图在 720p / 1080p 下按实际时间采样，5 秒约转 90°、20 秒转一圈。
既有 UI 回归通过；发布流程执行完整宿主测试、UBSan、Switch 三组件构建和附件回读校验。
