# CloudTune NX v0.2.0 · 开发预览

本版增加二维码多账号、AAC / FLAC 和独立 AirPlay 1 接收，并完善播放、会话存储与异常恢复。
CloudTune NX 仍为 **0.x 开发预览**；真实 Switch 上的游戏内 BGM、覆盖层共存和休眠恢复尚未完成实机验收。

## 本版内容

- **仅二维码登录**：移除密码、手机号和短信登录方式。支持保存最多 32 个账号，在「设置 → 账号管理」添加、切换或移除本机会话；可查看当前账号的喜欢、歌单、专辑、电台和云盘。
- **按音频内容自动识别格式**：支持 MP3、AAC（ADTS / M4A / MP4）和 FLAC，提供标准至 Hi-Res、超清母带等音源质量选项。已验证最高 24-bit / 192 kHz FLAC 音源；实际输出统一为**立体声 16-bit / 48 kHz**，多声道源混合为立体声，不是原规格直通。
- **AirPlay 1 独立工具**：无需网易云登录，在「设置 → AirPlay 1 接收」管理。首次默认开启，之后保留开关偏好；使用新版后台服务时，退出 NRO 后接收服务继续存在。支持同一局域网的单发送端经典音频投送，不包含 AirPlay 2、视频或屏幕镜像。
- **Switch 原生播放器**：保留中文手柄与触摸界面、33⅓ RPM 旋转黑胶唱片、封面和歌词。暂停时唱片静止，恢复播放后继续旋转；配套独立后台服务和 Tesla / Ultrahand 兼容覆盖层。

## 修复与可靠性

- 切换账号前清空原网易云队列，阻止旧队列从覆盖层恢复；已进行的 AirPlay 投送保持独立。
- 播放请求和缓存使用同一份已提交账号会话，避免保存中断时读取另一账号的 cookie 镜像。损坏记录、首次建档双重失败及失败后的重复保存都有保护与恢复提示。
- 修复过期或受限路径 cookie 被用于全局认证、退出时仍提交等待中的账号操作等问题；补充 IPC 输入、响应长度和会话隐私检查。
- 修复 MP3 精确跳转、未知长度 FLAC 跳转和孤立缓存标记恢复；完善 AAC / FLAC 渐进播放、取消与边界处理。
- 修复 AirPlay 命令边界、断开与音乐恢复、保存失败回滚等问题，并扩展分片控制请求、损坏数据包和反复连接测试。

## 下载与安装

| 附件 | 用途 |
| --- | --- |
| `CloudTuneNX-0.2.0-sd.zip` | 安装包，解压到 SD 卡根目录 |
| `CloudTuneNX-0.2.0-symbols.zip` | 配套 ELF 符号，留在电脑上排查崩溃 |
| `CloudTuneNX-0.2.0-docs.zip` | 离线文档、许可证与对应依赖源码 |
| `CloudTuneNX-0.2.0-manifest.json` | 源提交与文件哈希 |
| `SHA256SUMS` | 下载附件的 SHA-256 校验值 |

1. 下载 SD 包和 `SHA256SUMS`，在同一目录运行 `sha256sum --check --ignore-missing SHA256SUMS`，确认 SD 包显示 `OK`。
2. **只将 SD ZIP 解压到 SD 卡根目录**，保留目录结构。覆盖层需另行安装兼容的 Tesla / Ultrahand 加载器。
3. 重启进入 Atmosphère；按住 R 启动游戏，以完整应用模式打开 Homebrew Menu，再运行 CloudTune NX。
4. 进入「我的账号」，使用网易云音乐手机 App 扫描二维码并确认；在设置中管理账号和 AirPlay 开关。
5. 播放栏确认显示 **BGM · 后台服务** 后，再按[实机验收表](https://github.com/tiansongyu/cloudtune-nx/blob/v0.2.0/docs/HARDWARE_TESTING.md)测试退出 NRO、覆盖层和游戏共存。

更新时请同时替换 **NRO、后台服务和覆盖层**，然后重启；保留整个 `config/netease-switch/` 数据目录，只更新包内提供的 `cacert.pem`。
`exefs.nsp` 是 Atmosphère 系统模块，不能用游戏安装器安装。
完整布局见[安装指南](https://github.com/tiansongyu/cloudtune-nx/blob/v0.2.0/docs/INSTALLING.md)。

## 使用边界与反馈

曲目可用性、会员、地区和试听限制仍由网易云决定。AAC 精确跳转在长曲目上可能较慢，尾部索引的 M4A 需等待索引下载。
真实 Switch 的长期后台播放、游戏混音、网络切换、睡眠唤醒及实际 SD 断电恢复仍需用户实机测试。

请在 [Issues](https://github.com/tiansongyu/cloudtune-nx/issues) 提供版本、SHA-256、主机/Atmosphère/覆盖层版本和复现步骤。
不要上传账号记录、cookie、二维码、完整私有资料目录或音乐缓存。
