# CloudTune NX v0.2.1 · 覆盖层维护更新

本版集中修复 Tesla 覆盖层和后台 IPC 的可靠性问题，保留 v0.2.0 的二维码多账号、MP3 / AAC / FLAC、旋转黑胶和 AirPlay 1 功能。
仍为 **0.x 开发预览**，真实 Switch 的游戏内 BGM、覆盖层共存和休眠恢复需要实机验收。

## 修复

- **快进位置**：未知时长曲目可以正常前进 15 秒；接近位置上限时不会整数回绕到歌曲开头。
- **断线提示**：后台连接断开后清除旧标题、播放状态、时间、音量和循环模式；重连前禁用普通控制，保留启动 / 重连入口。
- **中文字体**：在非中文系统语言下也尝试使用系统简体中文共享字体；保留当前系统语言字体优先级，额外字体不可用时不阻断初始化。
- **长标题滚动**：换曲后重置滚动位置，避免新标题暂时消失；重复刷新相同标题不会打断滚动。
- **覆盖层资源与导航**：限制保留的字形缓存并释放位图，避免长期使用时持续增长；修复向上查找焦点时无符号索引回绕。
- **后台日志**：正常状态轮询不再持续写入 SD 卡；重复错误去重，IPC 诊断日志每次服务启动最多 64 KiB，日志写入失败不影响请求处理。

## 验证范围

新增回归测试直接执行覆盖层回调、从实际 libtesla 源码提取的字体 / 绘制 / 导航方法，以及实际 IPC 服务器请求处理代码。
测试使用合成数据和临时文件，覆盖未知时长跳转、断线与重连、中文字体回退、缓存回收、标题切换、连续轮询与错误日志上限。
完整宿主测试、UBSan、Switch 三组件交叉编译与安装包校验由本标签的 GitHub Actions 执行，成功后才发布附件。
本轮没有新增实机测试或真实 iPhone 人工听音结论，详细记录见[验证报告](https://github.com/tiansongyu/cloudtune-nx/blob/v0.2.1/docs/VALIDATION.md)。

## 下载与更新

| 附件 | 用途 |
| --- | --- |
| `CloudTuneNX-0.2.1-sd.zip` | 安装包，解压到 SD 卡根目录 |
| `CloudTuneNX-0.2.1-symbols.zip` | 对应 ELF 符号，留在电脑上排查崩溃 |
| `CloudTuneNX-0.2.1-docs.zip` | 离线文档、许可证与对应依赖源码 |
| `CloudTuneNX-0.2.1-manifest.json` | 源提交与文件哈希 |
| `SHA256SUMS` | 附件 SHA-256 校验值 |

下载 SD 包和 `SHA256SUMS`，在同一目录运行：

```bash
sha256sum --check --ignore-missing SHA256SUMS
```

确认 SD 包显示 `OK`，将其中内容合并到 SD 卡根目录，**同时更新 NRO、后台服务和覆盖层，然后重启**。
保留 `config/netease-switch/` 中已有账号、设置和缓存，仅替换包内提供的 `cacert.pem`。
覆盖层需要另行安装兼容的 Tesla / Ultrahand 加载器；`exefs.nsp` 是 Atmosphère 系统模块，不能用游戏安装器安装。

首次安装请参阅[安装指南](https://github.com/tiansongyu/cloudtune-nx/blob/v0.2.1/docs/INSTALLING.md)。
确认播放器显示 **BGM · 后台服务** 后，再按[实机验收表](https://github.com/tiansongyu/cloudtune-nx/blob/v0.2.1/docs/HARDWARE_TESTING.md)检查退出 NRO 和游戏共存。
反馈时请提供版本、主机 / Atmosphère / 覆盖层版本与复现步骤，不要上传账号、cookie、二维码或音乐缓存。
