# CloudTune NX v0.2.5 · 焦点、封面与首次播放修复

## 修改

- 打开原创榜等歌单时，加载期间保留选中卡片；目标页面到达后再初始化歌曲焦点。返回时同步恢复父页面与原来的焦点，避免瞬间跳回飙升榜。
- 封面纹理按最近显示时间回收，只在新一帧绘制前清理，避免缓存满后删除同一帧已经使用的图片。加载失败的可见封面每秒重试一次；封面到达后自动淡入。
- 尚未选择歌曲时，播放按钮、Y 键和空格会播放当前歌曲列表的第一首。在歌单卡片页，会打开第一个推荐歌单，加载完成后播放第一首。
- 重复按播放不会重复打开歌单；加载失败、账号变化或返回取消后，不会误播其他列表。已有歌曲和 AirPlay 的播放 / 暂停行为保持不变。
- 保留 20 秒一圈的黑胶动画和每日推荐 / 私人 FM 布局修复。

变更限于 Borealis 界面层，不修改音频解码、网络请求、账号存储、后台服务或 IPC 协议。公开版不含私人照片。

## 验证

- 新增回归覆盖榜单加载与返回、超过 48 张图片后的纹理存活、图片加载失败后的恢复，以及首次播放的成功 / 失败 / 取消 / 重复触发。
- 原生界面与实际 NRO 在隔离虚拟桌面检查；Eden 使用新配置、匿名数据验证真实榜单、封面和首次播放。原生界面检查 1280×720、1920×1080。
- 发布流程执行完整宿主测试、UndefinedBehaviorSanitizer、Switch 三组件构建和发布附件回读校验。

使用 SD 安装包更新，保留 `config/netease-switch/`。歌曲完整播放权限仍由网易云账号及曲目权益决定；实体 Switch 手柄与游戏共存需要实机验收。
