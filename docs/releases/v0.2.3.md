# CloudTune NX v0.2.3 · 每日推荐布局修复

## 修复

- 修复点击「每日推荐」后，歌曲列表与发现页横幅、标题互相遮挡的问题；私人 FM 的歌曲列表同样修复。
- 根据横幅下方的实际可用高度计算可见行数，预留焦点轮廓与底部播放栏间距。超出部分继续滚动浏览，最后一首仍可访问。
- 绘制、手柄滚动和触摸命中共用相同起点与行数，避免画面修正后点到其他歌曲。

本次只调整 UI 布局；音频、网络、账号与后台服务逻辑保持原样。公开版不含私人照片。

## 验证

新增每日推荐、私人 FM 的回归场景，覆盖横幅与标题边界、最后一行、滚动至末曲、触摸选曲及顶部导航。
该回归在修复前失败，修复后通过。原生界面检查覆盖 1280×720 和 1920×1080，以及带照片和通用主题。
发布流程执行宿主测试、UBSan、Switch 三组件构建及附件校验。

实机手柄、Atmosphère / Tesla 与游戏共存仍需在 Switch 上验收。

## 更新

使用本页 SD 安装包更新，保留 `config/netease-switch/` 下的账号、设置和缓存。
