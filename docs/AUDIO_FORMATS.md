# 音频格式与音质

播放器使用同一个解码模块处理前台 NRO、后台服务和桌面调试。
它读取文件内容选择解码器，不依赖文件扩展名、下载 URL 后缀或 CDN 的 MIME 标签。
无需手工选择 MP3、AAC 或 FLAC。

| 音频 | 支持范围 |
| --- | --- |
| MP3 | MPEG Layer III；保留原有缓存、暂停、拖动和队列播放 |
| FLAC | 原生 FLAC、Ogg FLAC，以及带 ID3 前缀的 FLAC；支持高位深、高采样率音源 |
| AAC | ADTS `.aac` 和 MP4 / M4A 中的 AAC 音轨 |
| AirPlay 1 | 独立的 ALAC / L16 PCM 接收路径；见 [AirPlay 文档](AIRPLAY.md) |

本功能不解密 DRM 音频，也不播放网易云的加密下载文件 `.ncm`。
收到不支持或损坏的音频时会反馈错误，并按队列规则处理下一首。

## 设置中的音源质量

| 界面 | API level |
| --- | --- |
| 标准 | `standard` |
| 较高 | `higher` |
| 极高 | `exhigh` |
| 无损 | `lossless` |
| Hi-Res | `hires` |
| 高清环绕 | `jyeffect` |
| 沉浸环绕 | `sky` |
| 超清母带 | `jymaster` |

标准、较高、极高分别请求 128 / 192 / 320 kbps。更高档位使用网易云
`songs_url_v1` 请求；实际编码、位深、采样率和是否只能试听由服务响应决定。
账号权益、地区、版权和曲目本身决定可用档位。选择高档位不会为原本的
低质量录音创造额外细节，也不保证服务器返回所选档位。
设置在下一次打开曲目时生效，现有音质偏好会保留。

**音源质量与输出格式是两回事。** 解码后的音频统一进入立体声 16-bit /
48 kHz 的播放管线，适配现有 Switch `audout` 和 AirPlay / 网易云音源交接。
高采样率音源会重采样，高位深音源会转换；多声道音源混合为立体声。
因此 Hi-Res、环绕或母带选项描述的是请求的音源，不代表原位深直通或
多声道硬件输出。
当前重采样沿用播放器的线性插值，尚未加入高阶抗混叠滤波。

## 下载、缓存与恢复

音频逐步下载到 SD 缓存，解码器在数据可用时开始读取，整首歌曲无需常驻内存。
尚未下载到的片段可能需要等待；M4A 的索引若位于文件末尾，首次开始播放也可能
需要下载至该索引。暂停、恢复和拖动都通过同一解码器路径处理。
AAC 为保持起始延迟补偿和精确定位，会从头解码并跳过目标之前的采样；
长曲目跳转可能比带索引的直接跳转更慢。
MP3 按实际可听采样位置向前解码，向后跳转时先回到开头，避免编码器延迟导致
定位偏移。没有声明总采样数的 FLAC 也通过解码跳过来定位。
这些路径均支持取消，但远距离跳转可能需要更长时间。

对于声明了可靠总采样数的 MP3，提前到达文件末尾会报告损坏。
没有可靠长度信息的 MP3 无法仅凭文件结束判断所有截断情况。

新缓存统一使用 `.audio`，完成下载后才写入 `.complete` 标记。
旧版完整的 `.mp3` 缓存仍可读取。缓存按登录会话与请求音质区分，
不会将匿名试听缓存当成另一个账号的完整曲目。
单曲最多 512 MiB；清理时保留最多 512 MiB 的其他缓存，
加上正在播放 / 下载的曲目，总音频缓存目标不超过约 1 GiB。
空间限制针对 SD 文件，而不是音频 RAM 缓冲。

解码测试使用生成的音频，覆盖不同位深和采样率、错误文件后缀、损坏输入、
混合格式队列、拖动和渐进下载。通过测试的精确范围见
[验证报告](VALIDATION.md)；Switch 与游戏同时播放仍需实机验收。
