# 黑胶旋转周期校准 · v0.2.4

## 官方参考

2026-10-21 从[网易云官方歌曲分享页](https://music.163.com/m/song?id=186016)读取其引用的
[Song$id$Index.64ac09c7ebc132715e3e.css](https://s3.music.126.net/mobile-new/Song$id$Index.64ac09c7ebc132715e3e.css)。
`.a-circling` 的声明为 `animation:circling 20s linear infinite`，关键帧由 0 转到 1 turn，
暂停类通过 `animation-play-state:paused` 保留角度。

这确认了该官方网页经典黑胶的 **20 秒一圈**、线性循环和暂停行为。
不将复刻教程作为官方证据，也不推断所有移动客户端版本或付费播放器皮肤均相同。
参考样式 SHA-256：`985684cc3958f66fe213de7bd3ea77a1a3e0415f290054e551f86ed97687defc`。

## 改动范围

原生角速度从每秒约 3.4906585 弧度（1.8 秒一圈）调整为 `2π / 20`（18°/秒）。
继续按实际帧间隔累加，顺时针匀速旋转。播放状态与「减少动态」条件、唱臂、
暂停保留角度的逻辑不变。仅视觉动画变慢，不改变音频播放速度。
设计 token、Web 原型和当前设计规范同步更新；历史版本发布说明保留原记录。

## 验证

- 桌面生产 UI 构建成功，既有 UI 布局与控制回归通过（2/2）。
- 隔离虚拟桌面分别以 1280×720、1920×1080 渲染生产 `MusicView`。
  在 0 / 5 / 10 / 15 / 20 秒捕获画面，以中心封面方向估计角度。
  两种分辨率的阶段角度均在理论值 2° 以内，20 秒约回到初始方向，符合 20 秒一圈。
  帧采样包含调度和截图延迟，不将图像估计当成精确计时仪器。
- Switch NRO、后台服务与覆盖层构建通过；实际照片版 NRO 在全新隔离 Eden 配置启动。
  匿名 FM 播放约 5.30 秒转 96.16°，暂停 2 秒时唱片采样完全一致，
  恢复播放约 5.29 秒转 94.90°，与每秒 18° 的目标一致。
- 完整宿主、UBSan、公开安装包及附件回读校验由
  [v0.2.4 发布流程](https://github.com/tiansongyu/cloudtune-nx/releases/tag/v0.2.4)执行。
