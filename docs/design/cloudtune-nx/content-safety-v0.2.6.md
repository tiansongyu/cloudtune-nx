# v0.2.6 列表身份与误播防护

## 两条原因与修改

1. `browse()` / `search()` 提前改变页面身份，旧 `items` 却直到请求成功才替换。失败时新页面会保留上一页歌曲。现在新根页面、搜索和子栏目一起重置内容字段与标题；歌曲队列独立保留。分页追加保留当前列表，不能使用同一种清空方式。
2. 绘制使用每 200 ms 更新的 `display_`，触摸命中和激活却读取最新 Model 快照；`play(index)` 又取一次快照。两次更新窗口都可能让同一行号指向另一首歌。现在触摸命中、方向键移动、A 激活和首次播放使用显示快照；Model 在同一个锁内校验内容代次、页面、账号与歌曲 ID，查找规范列表位置并复制播放队列。

内容代次在新页面请求、歌单到达、返回和账号重置时递增。图片、元数据及分页更新不会改变其归属。过期页面操作不执行；同一列表的歌曲重排仍能按 ID 正确选中。歌单打开期间继续保留父卡片焦点，成功到达后再切换，延续 v0.2.5 的过渡修复。

## 验证证据

- 新 `ui-content-safety` 测试在旧生产代码上出现 12 条失败，分别覆盖切页后的旧歌曲、搜索失败、触摸与手柄在刷新窗口的错位、首次播放、删除、账号/歌单变化及队列重排。
- 修复后增加新根栏目、分页失败、同路由代次变化，以及 UI 校验后 Model 再次变化的检查。完整桌面 CTest 26/26 通过（102.28 秒）；原有焦点、封面、首次播放、账号、音频和服务测试保留。
- Switch 前台 NRO、后台 NSP、覆盖层构建成功。
- 原生视图检查 1280×720 和 1920×1080 的推荐歌曲、焦点与控制栏。中文布局正常。
- 实际照片 NRO 使用新建 Eden 配置、匿名服务数据与仅对该配置生效的本地代理开关。FM 已加载歌曲后断开测试代理，切换排行榜：标题为排行榜、内容为空并出现错误，按 Y 后仍未开始播放。恢复代理后按 A 成功重新加载 64 张榜单卡片。
- 进入原创榜，触摸第三首后，行高亮、歌曲标题、封面与小播放器一致；方向键向下加 A 播放第四首，结果一致。Y 暂停、X 弹窗、B 返回后保留原创榜卡片焦点。实际 NRO 的 1080p 排行榜缩放也通过目视检查。

日志和截图保存在忽略目录 `build/validation/content-safety/`。其照片、模拟器配置和匿名缓存不会上传。确定性生产视图测试负责覆盖短于一帧的并发窗口；普通模拟器点选不作为该并发修复的唯一证明。

## 范围

本版处理审查中的两项高优先级误播问题。损坏图片磁盘缓存、歌单头图的独立请求、加载中返回取消及部分子页重试路由等其他审查项不作为本版已修复内容。未改变音频解码、请求传输、服务实现和 IPC；模拟器与 CI 结果不代替实体 Switch 和游戏共存验证。
