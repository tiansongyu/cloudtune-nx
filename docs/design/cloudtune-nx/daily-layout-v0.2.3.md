# 每日推荐布局修复 · v0.2.3

## 原因与修改

每日推荐和私人 FM 在发现页内把歌单卡片替换为歌曲列表，页面仍保留横幅、
标题和顶部操作。歌曲列表此前沿用普通列表的纵坐标 210 与六行容量，导致
前两行进入横幅和标题区域。

现在发现页的卡片与歌曲统一从逻辑坐标 292 开始；可见歌曲行数按底部播放栏
之前的实际空间计算，并为焦点轮廓保留间距。发现页可完整显示四行，收藏详情
和普通歌曲列表分别保持五行和六行。更多歌曲通过原有滚动逻辑访问。
绘制、触摸和手柄导航共用布局结果，音频、网络、账号与后台服务未改动。

## 验证记录

- 新增的每日推荐 / 私人 FM 回归用例在旧代码上失败，修复后通过。
- 生产 `MusicView` 测试覆盖顶部操作与歌曲的边界、末行焦点、滚动至最后一首、
  首尾歌曲触摸索引及返回顶部操作区；照片资源存在与缺失时各通过 2/2 UI 测试。
- 布局检查覆盖 720p、1080p、非 16:9 窗口及 100% / 95% / 90% 安全区的触摸坐标。
- 在隔离虚拟桌面检查 720p / 1080p 的照片版和通用版。原生截图使用合成音乐数据，
  不包含用户账号、私人照片或真实歌单。
- 编译 NRO、后台服务和覆盖层。用全新 Eden profile 启动实际照片版 NRO，
  触摸进入私人 FM，匿名网络返回歌曲后确认布局正常。未复制登录凭据；
  登录后的每日推荐多行场景由原生生产视图夹具和回归测试覆盖。
- 完整宿主、UBSan 与公开安装包验证由该版本的 Release 工作流执行，
  最终状态见 [v0.2.3 发布页](https://github.com/tiansongyu/cloudtune-nx/releases/tag/v0.2.3)。
  实体 Switch 手柄和游戏共存仍需实机验收。
