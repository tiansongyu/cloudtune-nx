# 二维码登录与多账号

CloudTune NX 仅提供二维码登录，不再包含密码登录、手机号登录或短信发送入口。
使用网易云音乐手机 App 扫描屏幕上的二维码，并在手机上确认授权。

## 添加与切换

1. 首次登录可打开「我的账号 → 扫码登录 / 刷新二维码」。
2. 添加另一个账号时，打开「设置 → 账号管理 → 扫码添加账号」。
3. 在手机端切换到希望添加的网易云账号，再扫码并确认。
4. 在账号管理中选择保存的账号，即可切换；当前账号有标记，列表同时显示昵称和 UID。

最多保存 32 个账号。同一 UID 再次扫码会更新已有会话，不产生重复账号。
账号授权有可能过期；遇到服务提示登录失效时，重新扫码更新对应会话。
本地保存不会延长服务端授权，也不会改变会员、地区或曲目权限。

生成新二维码使用独立的内存会话。等待、扫码未确认、过期、刷新、按 B 取消
或离开页面，都不会覆盖原账号。过期或已取消的二维码响应不能激活旧登录请求。

切换账号会先停止网易云播放、清空旧队列，再切换会话；打开音乐库时重新读取资料库。
喜欢列表、歌词、页面历史及旧的异步请求结果均按账号隔离，避免旧账号数据
出现在新账号页面中。旧队列也不能从覆盖层恢复播放。
AirPlay 是独立工具，正在进行的投送可继续；切换后不再恢复原账号的网易云队列。

## 从本机移除

选择账号后使用「从本机移除」并确认。此操作只移除该账号的本地会话，
不删除网易云账号，也不在服务器上注销其他设备。
移除非当前账号不会停止当前网易云播放。
移除当前账号后保持未登录状态，不会自动选择其他人的账号。

## 文件与旧版本迁移

数据目录仍为 Switch SD 卡上的 `config/netease-switch/`：

| 文件 | 用途 |
| --- | --- |
| `accounts.json` | 本地账号记录、会话和当前账号；凭据文件，必须保密 |
| `cookies.txt` | 当前账号的 Netscape cookie 镜像，供独立后台服务只读使用 |
| `queue.nsq` | 当前播放队列；账号边界完成后清空 |
| `settings.json` | 共用音质和网络代理设置 |
| `airplay.json` | 独立的 AirPlay 接收设置 |

旧版本只有 `cookies.txt` 时，首次成功确认账号身份后自动迁移。
无需删除原数据目录或重新命名文件。账号记录采用可恢复的事务保存；
在 Horizon 的两次重命名之间中断时，可以读取上一个已提交的 `.bak`。
重启时以已提交的账号记录恢复当前 cookie 镜像。

请同时更新 NRO、后台服务和覆盖层，并重启主机。旧后台若不支持清空账号队列，
切换会提示更新，而不会在旧队列尚未清除时切换账号凭据。
数据文件不是加密保险库；不要公开分享整个数据目录、cookie、账号记录、
备份或二维码。详见 [账户数据说明](../SECURITY.md)。
