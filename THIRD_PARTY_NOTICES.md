The filenames `switch_font.ttf` and `switch_icons.ttf` match Borealis's
resource convention; their contents are DejaVu Sans and text-based controller
hints generated by `scripts/make-controller-font.py`. Proprietary reference
font assets have been replaced. The application's music canvas uses the OFL
Noto font. Nintendo Switch systems expose their own shared fonts through
libnx; the current release does not bundle those system font files.
The published Git history also uses the licensed replacements in earlier
snapshots and includes the DejaVu license from the initial commit.

devkitPro, libnx, libcurl, mbedTLS, zlib, Mesa and SDL are supplied by the
toolchain or host under their own licenses. Version information is retained
with build validation; dependency notices are not replaced by the project's
top-level license.

## Local Borealis changes

- Removed the optional `SetWirelessPriorityMode` call. Eden v0.2.1 aborts on
  that unimplemented service command. Music playback does not need this hint.
- Build consumers explicitly provide the vendored nlohmann/json include path.
- HID touch coordinates are mapped from the panel's 1280×720 space to the
  logical canvas, independent of a docked framebuffer's scale.

The application and service use GPL-3.0-or-later. The independently loaded
overlay uses GPL-2.0-only and communicates through the GPL-2.0-or-later C ABI.
